# Why the rules exist

The incidents behind the rules in `SKILL.md` and the phase files. Each rule stays where it is; this
file keeps the story.

## An instruction that argues with itself is obeyed selectively

Phase 3's checkpoint once read *"NO HITL GATE HERE, proceed immediately"*, contradicting §3.1b four
lines above it and `SKILL.md`, which then named Phases 1, 2 and 3 as gated. An instruction that
argues with itself is obeyed selectively, which is the same as not existing. When a phase file and
`SKILL.md` disagree, fix both in the same commit.
